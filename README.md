# Chan

A cute, configurable desk companion firmware for the M5Stack Stack-chan (ESP32-S3).
Talk to it with Gemini's realtime voice model (with web search and camera), see whether your
coding agents (Claude Code, Codex, Gemini CLI…) need you, follow your teams live and watch it
celebrate every goal, and glance at the clock and weather while it idles.

Sibling of [Dash](https://github.com/xavidop/dash).
